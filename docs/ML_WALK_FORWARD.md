# 고정 후보의 walk-forward 안정성 점검

브랜치: `codex/ml-walk-forward`. 기반: `codex/ml-regularization-ablation` ([PR #3](https://github.com/kk53451/J-StockLab/pull/3)).

## 무엇을 확인하는가

이전에는 2021년까지 학습한 모델 하나를 2022~2023년 전체에서 평가했다. 이번에는 각 분기 직전까지의 데이터를 모두 사용해 다시 학습하고, 다음 분기를 평가한다. 과거 학습 구간의 시작은 유지하고 끝만 늘리는 expanding-window 방식이다.

예를 들어 2022년 1분기를 예측할 때에는 2021년 말까지의 데이터만 학습에 포함한다. 2분기를 예측할 때에는 1분기 데이터도 이미 과거이므로 학습에 추가한다. 모든 학습 타깃은 해당 재학습 cutoff 이전에 관측돼 있어야 한다.

## 실행 전에 고정한 조건

- 기간: 2022Q1 ~ 2023Q4, 분기별 8개 fold.
- 후보: 상대 입력·상대 타깃 Ridge, alpha=10000. 추가 튜닝과 후보 선택 없음.
- 학습: 2014년 데이터 시작점부터 해당 분기 직전까지 확장. 스케일러도 각 fold의 학습 구간에서 새로 fit.
- 비교: 현재 가격 유지, 매 분기 다시 계산한 학습 평균 변화율, 매 분기 재학습한 Ridge.
- 대조군: 첫 fold의 Ridge와 scaler를 이후 모든 분기에 그대로 적용한 `ridge-fixed`.
- 공통 입력: 20개 주가, 90거래 세션. 타깃: 다음 7거래 세션.
- 각 분기의 모든 타깃이 그 분기에 들어오는 창만 평가. 다음 분기로 넘어가는 창은 모든 모델에서 동일하게 제외.
- pooled 지표는 모든 fold의 origin을 합쳐 종목·horizon에 동일 가중치로 계산. 분기별 승패와 연도별 수치는 진단용이며 유의성 검정이 아님.
- 2024년 이후 값은 전처리 입력에서 제외. 각 fold는 평가 종료일 이후 시퀀스도 생성하지 않음.

`ridge-fixed`도 재학습 모델과 완전히 같은 origin·타깃을 평가한다. 그래서 원래 2년 전체 평가 점수와 다른 평가일 구성 때문에 생기는 혼동 없이 재학습의 영향을 비교할 수 있다. 상대 입력은 각 origin의 가격 비율이므로 fitted input scaler가 없고, 고정 모델의 출력은 반드시 첫 fold의 target scaler로 복원한다.

## 해석의 한계

**alpha=10000은 이미 2022~2023년 결과를 보고 선택한 값이다.** 이번 점검은 모델·scaler를 과거 구간으로만 fit하지만 후보 선택까지 미래를 보지 않았던 실전 시뮬레이션은 아니다. nested 검증이나 새로운 미관측 테스트라고 부르지 않는다.

기존 스냅샷의 수정 이력·발표 시점·과거 bfill·당시 구성종목 문제도 남아 있다. 분기 내 이웃한 origin들의 정답 기간이 겹치므로 개별 예측들을 독립 표본으로 취급한 신뢰구간이나 유의성 주장을 하지 않는다.

## 실행

```powershell
.venv-ml/Scripts/python.exe -m ml_eval.walk_forward --output artifacts/walk-forward-v1
```

`manifest.json`에 후보·분기 경계·설정·데이터/코드 해시를 학습 전에 기록한다. 각 분기 디렉터리에는 Ridge·평균 변화율 모델, scaler, 타깃 범위, 네 모델의 예측·지표가 저장된다. `aggregate/`에는 fold 식별자를 포함한 합산 예측과 종목·horizon별 지표를 저장하고 `comparison.json`으로 전체 및 분기별 결과를 제공한다. 모델/출력은 Git 제외 대상이며 요약 결과를 별도 문서에 기록한다.

`load_frame(..., end_date=...)`는 cutoff 이후 값을 숫자 전처리 전에 제외한다. `make_dataset(..., include_test=False)`는 train/validation만 만들고 평가 종료일 뒤의 행을 제거한다. 기존 단일 분할 CLI의 기본 동작은 유지된다.

## 실제 결과

[분기별 수치·설정·데이터/코드 해시](results/walk_forward_2026-09-08.json)를 기록했다. 8개 분기에서 합계 **442개 origin**, origin마다 20종목 × 7세션을 평가했다.

| 모델 | 전체 MAPE (%) ↓ | 기준선보다 낮은 MAPE를 낸 분기 |
| --- | ---: | ---: |
| 현재 가격 유지 | 2.749547 | — |
| 분기별 학습 평균 변화율 | 2.749620 | 2 / 8 |
| 분기별 재학습 Ridge | **2.742824** | **5 / 8** |
| 첫 모델을 유지한 Ridge | 2.744270 | 4 / 8 |

재학습 Ridge의 전체 MAPE는 persistence보다 **0.006723%p**, 고정 Ridge보다 **0.001446%p** 낮다. 평균 오차 개선은 작다. 고정 Ridge와 분기별로 비교하면 재학습이 나은 분기 4개, 나쁜 분기 3개, 같은 분기 1개다. 첫 분기는 두 모델이 동일하므로 결과도 같아야 한다.

이전 단일 분할은 484개 origin이었다. 이번에는 7개의 추가 분기 경계에서 6개씩, 총 42개 창을 더 제외해 442개가 됐다. **기준선 값이 이전의 2.7294%와 달라진 이유는 평가 날짜가 달라졌기 때문이다.** 개선 효과는 이번 표의 같은 날짜끼리 비교해야 한다.

## 확인한 사항

- 전체 테스트 **61개 통과**(TensorFlow 포함 기존 모델 테스트 유지).
- 뒤쪽 가격을 크게 바꿔도 앞선 분기의 예측이 변하지 않음을 합성 데이터로 검증.
- 모든 fold의 학습 타깃이 재학습 cutoff 이하이며 평가 타깃은 fold 사이에 중복되지 않음.
- 고정 모델의 뒤쪽 분기 예측을 첫 fold 모델·scaler만으로 재현.
- 2024년 이후 행은 숫자 전처리 이전에 제거. 원본 CSV 4,069행 중 cutoff 이후 705행을 제외하고, 실제 모델 입력에 사용 가능한 과거 거래 세션은 2,250개.
- 기존 테스트 구간은 평가하지 않았고 신규 `test/` 결과도 생성하지 않음.
- 외부 라이브러리의 deprecation 경고는 남아 있으나 테스트와 실제 실행은 완료.

## 이번 결과의 의미

분기별로 다시 학습한 모델이 평균적으로 아주 조금 나아졌지만, 기간별 우위는 일관되지 않았고 재학습 자체의 추가 효과도 작았다. 이 결과는 안정성에 대한 한계를 구체적으로 보여준다. 새로운 모델을 계속 추가하기 전에 오차가 큰 종목·horizon·시장 구간을 살펴볼 근거가 생겼다.

포트폴리오에는 “walk-forward에서 높은 예측력을 확보했다”는 주장보다, **검증 방식을 강화해 미세한 평균 개선과 기간별 불안정성을 구분했으며 최종 테스트를 보존했다**는 내용으로 기록하는 것이 결과에 부합한다.
