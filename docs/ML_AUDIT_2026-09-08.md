## 이번 개선의 완료 기준

- 기존 과제와 독립된 평가 CLI 및 실행 설명 제공.
- 거래 세션 기준 시퀀스와 타깃 날짜 분리, 학습 전용 스케일러 검증.
- persistence / Ridge 및 선택적 LSTM / Transformer를 같은 평가 규약으로 실행.
- validation을 이용한 모델 선택과 최종 test 평가를 별도 명령으로 분리.
- 종목·horizon별 MAE/RMSE/MAPE, 방향 일치율, 기준선 대비 오차 비교 저장.
- 미래 극단값, 분할 경계, 예측 날짜, 모델 저장·복원 등에 대한 회귀 테스트.
- 실제 실행 결과와 미해결 데이터 한계를 기록. 새로운 모델의 우수성을 미리 주장하지 않음.

## 남는 데이터 한계

기존 CSV는 이미 정제된 과거 스냅샷이다. 거래일 필터나 한 세션 지연만으로 발표 시점, 수정 GDP, 과거 bfill, 현재 구성종목 선택에 따른 생존편향, 수정주가의 당시 가용성을 복원할 수 없다. 새 파이프라인의 결과는 이 스냅샷 내 시간순 평가이며, point-in-time 데이터 기반 실전 성능 검증이 아니다. 추후 원시 데이터와 발표 시점·당시 구성종목을 보존하는 수집 경로가 필요하다.
