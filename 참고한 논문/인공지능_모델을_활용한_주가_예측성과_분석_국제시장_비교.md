# 1. 서지 정보 요약

- **제목:** 인공지능 모델을 활용한 주가 예측성과 분석 – 국제시장 비교
- **저자:** 김태현
- **학위:** 석사학위논문 (국민대학교 비즈니스IT전문대학원)
- **발행:** 2022
- **연구 대상:** KOSPI, S&P 500, Nikkei225
- **모델:** XGBoost, LSTM, CNN
- **예측 목표:** 다음날 종가 방향(Up/Down) 분류 문제

---

# 2. 핵심 주장 / 연구 목적

- 인공지능 기반(AI·DL) 모델이 **불규칙적이고 비선형적인 주가 예측에서 전통적 통계 모델의 한계를 보완할 수 있는지 검증**하는 연구.
- 특히 **세 국가(KOSPI, S&P500, Nikkei225)**에 동일한 모델을 적용함으로써 “국제시장 간 예측 성능 비교”를 수행한다는 점이 차별점.
- 랜덤워크/효율적 시장가설로 제기되는 “주가는 예측 불가능” 논쟁을 고려하되,  
  **AI 비모수 모델은 패턴을 포착하고 의미 있는 정확도를 달성할 수 있다**는 관점에서 접근.
- XGBoost, LSTM, CNN 세 모델의 **정확도·F1-score·손실값**을 비교하여 실제 투자 전략으로 연계 가능성을 평가.

---

# 3. 주요 발견(핵심 결과)

## 3.1 XGBoost가 전체적으로 가장 높은 성능

- **평균 예측 정확도: 56.88%** (세 국가 평균)
- 국가별 최고 정확도:
  - **KOSPI: 61.91%**
  - S&P500, Nikkei225도 50% 중반대 유지
- 결론: “부스팅 기반 트리 모델이 LSTM, CNN 대비 강건한 성능”

## 3.2 LSTM 결과

- 일별 시계열 특성 포착은 가능하나 **학습 불안정성**으로 인한 예측력 변동 존재.
- 정밀도·재현율에서 균형적이지만 XGBoost 대비 우수한 결과는 아님.

## 3.3 CNN 결과

- 캔들스틱 이미지를 기반으로 예측한 모델로 **직관적 시각 패턴 인식 성능**은 보였으나
- 구조 특성상 **시계열의 장기적 의존성 반영에 한계**
- 정확도 평균적으로 가장 낮음.

## 3.4 국제시장 비교 인사이트

- 세 시장 모두 예측 가능성이 존재하나  
  **한국(KOSPI) > 미국(S&P500) > 일본(Nikkei225)** 순으로 정확도 높게 나타남.
- 일본 시장(Nikkei225)은 변동성·거시 이벤트 의존성이 강해 **AI 모델 예측 난이도가 상대적으로 높음**.

---

# 4. 프로젝트 적용 포인트 (일본 주가 예측 프로젝트 관점)

### 4.1 “선행연구 정리(2장)”에 활용

- 주가 예측은 랜덤워크/EMH vs 비모수·AI 모델 가능성이라는 **두 학파의 대립 구조**를 설명할 때 근거로 사용.
- 인공지능 모델을 통한 예측 성공 사례(XGBoost 56~61% 성능)를 인용하면 좋은 대비 효과.

### 4.2 “문제 정의(2장)”과 모델 선택 근거

- LSTM·Transformers 같은 시계열 딥러닝 모델이  
  “비선형·장기 의존성 포착”을 위해 사용되는 배경을 설명하는 데 적합.
- CNN은 캔들스틱 등 이미지 패턴을 활용하는 접근이 가능하다는 점을 보조 설명으로 활용.

### 4.3 “데이터 설명(3장)”에 적용

- 20년간 KOSPI/S&P500/Nikkei225 종가 기준 5000일 데이터 사용 →  
  **일본 Nikkei225 장기시계열 데이터 사용 근거**로 활용 가능.

### 4.4 “결과 분석(5장)”에서 비교 연구로 활용

- XGBoost가 LSTM 대비 높은 정확도를 보였다는 점은  
  “Transformer vs LSTM vs Linear Regression” 비교 시 참고 근거가 됨.
- 특히 **일본 시장은 예측 난이도가 상대적으로 높다는 점** 인용 가능.

### 4.5 “한계점 및 향후연구(6장)”에서 연계

- 본 논문도 시장별 예측 난이도 차이, 비정상성, 거시 변동성 문제를 언급하므로  
  향후 연구에서 **거시 변수(FED금리·환율·상품가격) 추가** 논리 강화 가능.
- 너의 프로젝트에서 시도하는 Transformer 기반 접근이 **본 논문의 CNN/LSTM 대안 모델**로 자연스럽게 이어짐.

# 5. 인용하기 좋은 문장 (페이지 번호 포함)

> “본 연구에서 XGBoost 모델은 세 국가 모두에서 평균 56.88%로 가장 높은 예측 정확도를 보였다.” (p.8 국문요약)

> “KOSPI 주가지수는 61.91%의 예측 정확도를 기록하며 세 지수 중 가장 높은 성과를 보였다.” (p.21~22)

> “인공지능 모델은 전통적 선형모형으로 설명하기 어려운 비선형적 패턴을 포착하여 주가 예측에 활용 가능성을 보여준다.” (p.2)

> “Nikkei225는 변동성이 상대적으로 높아 예측 난이도가 큰 시장임을 확인할 수 있다.” (p.22 요약 해석)

> “본 연구는 AI 모델을 국제시장에 동시에 적용하여 국가별 예측 성과 차이를 검증했다는 점에서 의의가 있다.” (p.8)

---

# 6. 초간단 요약 (3~5줄)

이 논문은 XGBoost, LSTM, CNN 세 인공지능 모델을 활용하여 KOSPI·S&P500·Nikkei225의 다음날 종가 방향을 예측한 국제시장 비교 연구이다. XGBoost가 평균 56.88%로 가장 우수한 성능을 보였으며, KOSPI가 가장 예측 용이하고 Nikkei225가 가장 어려운 시장으로 나타났다. 이는 일본 주가 예측에서 딥러닝 모델 선정, 데이터 구조 설명, 선행연구 정리에 직접적으로 활용 가능한 근거를 제공한다.
