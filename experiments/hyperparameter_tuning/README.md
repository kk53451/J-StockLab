# Hyperparameter Tuning 실험

> **실험 목적**: Sensitivity Analysis를 통해 각 하이퍼파라미터의 영향을 분석하고, 현재 설정이 최적임을 검증

---

## 1. 실험 목적 및 목표

### 왜 이 실험을 진행했는가?

딥러닝 모델의 성능은 하이퍼파라미터 설정에 크게 의존합니다. 본 프로젝트에서 사용한 LSTM 모델의 하이퍼파라미터가 **경험적으로 선택**되었기 때문에, 체계적인 분석을 통해:

1. 현재 설정이 최적인지 검증
2. 각 하이퍼파라미터가 성능에 미치는 영향 분석
3. 개별 변경과 복합 조합의 효과 비교

### 실험 목표

| 목표                     | 설명                                                    |
| ------------------------ | ------------------------------------------------------- |
| **Sensitivity Analysis** | Baseline 기준으로 각 파라미터를 개별 변경하여 영향 분석 |
| **복합 조합 탐색**       | Balanced, High-Capacity 설정 비교                       |
| **현재 설정 검증**       | Baseline(LSTM=128)이 최적인지 확인                      |

---

## 2. 실험 과정

### 2.1 Baseline 설정

```python
# Baseline (현재 설정)
lookback = 90          # 과거 90일 데이터 사용
lstm_units = 128       # LSTM 레이어 유닛 수
dense_units = 128      # Dense 레이어 유닛 수
dropout_rate = 0.2     # 드롭아웃 비율
learning_rate = 0.0001 # 학습률
batch_size = 32        # 배치 크기
```

### 2.2 실험 구성 (8개)

| #   | 설정명         | LB  | LSTM | Dense | DR   | BS  | 변경점       |
| --- | -------------- | --- | ---- | ----- | ---- | --- | ------------ |
| 1   | **Baseline**   | 90  | 128  | 128   | 0.2  | 32  | -            |
| 2   | Lookback↑(120) | 120 | 128  | 128   | 0.2  | 32  | LB +30       |
| 3   | LSTM↓(64)      | 90  | 64   | 128   | 0.2  | 32  | LSTM -64     |
| 4   | Dense↓(64)     | 90  | 128  | 64    | 0.2  | 32  | Dense -64    |
| 5   | Dropout↓(0.15) | 90  | 128  | 128   | 0.15 | 32  | DR -0.05     |
| 6   | Batch↑(64)     | 90  | 128  | 128   | 0.2  | 64  | BS +32       |
| 7   | Balanced       | 90  | 128  | 64    | 0.15 | 32  | Dense↓ + DR↓ |
| 8   | High-Capacity  | 120 | 128  | 128   | 0.2  | 64  | LB↑ + BS↑    |

### 2.3 평가 방법

- **Metric**: Validation Loss (MSE)
- **Early Stopping**: patience=5, 과적합 방지
- **Train/Val Split**: 80% / 20%

## 4. 결론 및 인사이트

### 4.1 핵심 결론

**Baseline이 1위!** 현재 설정이 모든 변형 중 최고 성능을 기록했습니다.

```
┌─────────────────────────────────────────────────────────────────────┐
│                    검증된 최적 설정 (Baseline)                        │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Lookback = 90일                                                 │
│     - 120일은 오히려 노이즈 증가로 성능 저하                         │
│                                                                     │
│  LSTM Units = 128                                                │
│     - 64보다 128이 명확히 우수                                      │
│     - 충분한 표현력으로 시계열 패턴 학습                            │
│                                                                     │
│  Dense Units = 128                                               │
│     - 64로 줄이면 성능 저하                                         │
│                                                                     │
│  Dropout = 0.2                                                   │
│     - 0.15보다 0.2가 과적합 방지에 효과적                           │
│                                                                     │
│  Batch Size = 32                                                 │
│     - 64보다 32가 안정적인 학습 제공                                │
│                                                                     │
│  Best Validation Loss: 0.0358                                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.2 파라미터별 인사이트

| 파라미터    | 현재 값 | 실험 결과  | 결론 |
| ----------- | ------- | ---------- | ---- |
| LSTM Units  | 128     | 128 > 64   | 최적 |
| Dense Units | 128     | 128 > 64   | 최적 |
| Dropout     | 0.2     | 0.2 > 0.15 | 최적 |
| Lookback    | 90      | 90 > 120   | 최적 |
| Batch Size  | 32      | 32 > 64    | 최적 |

### 4.3 복합 조합 분석

| 조합                      | Val Loss | Baseline 대비 |
| ------------------------- | -------- | ------------- |
| Balanced (Dense↓ + DR↓)   | 0.0390   | -8.9%         |
| High-Capacity (LB↑ + BS↑) | 0.0366   | -2.2%         |

복합 조합도 Baseline보다 성능이 낮음 → 현재 설정이 이미 최적의 균형점
